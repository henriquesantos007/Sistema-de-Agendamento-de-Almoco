# Glossário do Sistema de Agendamento de Almoços

| Termo | Definição |
|---|---|
| Administrador | Perfil responsável por tarefas administrativas, incluindo gerenciamento de usuários e restaurantes no sistema. |
| Agendamento | Registro de uma solicitação de almoço feita por um estudante para uma data específica com base no cardápio publicado. Funciona como sinônimo de "Pedido". |
| Cardápio | Conjunto de pratos/ofertas disponibilizados por um restaurante para uma data específica (Diário) ou intervalo de datas (Semanal). |
| Estudante | Usuário cadastrado com matrícula da UFPB que consulta ofertas, agenda almoços e realiza pagamentos. |
| Estorno | Devolução automática de um pagamento previamente aprovado, acionada quando o restaurante cancela um pedido. |
| Gateway de Pagamento | Sistema externo responsável por processar os pagamentos via PIX ou cartão de crédito e efetuar estornos. |
| Gestor de Restaurante | Usuário responsável por gerenciar os dados do restaurante, cadastrar pratos, publicar cardápios e acompanhar pedidos. |
| Indisponibilidade | Status ativado pelo Gestor de Restaurante informando que um prato/oferta acabou ou não pode mais ser servido no dia. |
| Item de Cardápio | Oferta de um prato em uma data específica, que pode possuir uma quantidade máxima disponível. |
| Prato | Preparação ou alimento individual cadastrado no catálogo base do restaurante. |
| Restaurante | Estabelecimento parceiro que fornece as refeições para os estudantes do CI. |
